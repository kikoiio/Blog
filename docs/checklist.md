# 星图索引与项目清理 Checklist

> 每项均通过实际构建、浏览器操作、文件审计或版本差异验证。清理候选在用户批准前只记录，不删除。

## 实现完整性

- [ ] 顶层目录仍由力导向图展示，目录节点可展开、收起、拖动和缩放（验证：启动本地站点，在桌面浏览器逐项操作，期望图响应正常且控制台无错误；覆盖 AC1）。
- [x] 二级及更深目录打开索引轨道，而不是生成文章图节点（验证：展开一级目录后点击二级目录，期望出现文章列表，图中不存在该目录的文章节点；覆盖 AC2、AC9）。
- [x] 一级叶子目录直接打开索引轨道（验证：使用包含一级叶子目录的隔离内容数据启动站点，点击该目录，期望直接显示列表；覆盖 AC2）。
- [x] 索引递归包含当前目录的全部后代笔记（验证：使用包含多级子目录的隔离内容数据，比较列表条目与该目录全部文章，期望数量和链接一一对应；覆盖 AC2）。
- [x] 笔记按照显示名称稳定升序排列（验证：使用包含中文、英文和数字标题的隔离内容数据连续刷新两次，期望顺序符合区域感知名称升序且两次完全一致；覆盖 AC3）。
- [x] 重复标题能够通过相对目录路径区分（验证：使用两个不同目录下的同名笔记，期望两个条目均显示各自路径；非重复标题不显示多余路径；覆盖 AC3）。
- [x] 索引显示当前目录名称、完整路径和准确文章数量（验证：打开不同层级目录，期望标题、路径、数量随目录正确更新；覆盖 AC4）。
- [ ] 点击列表条目进入正确文章（验证：分别打开至少两个条目，期望浏览器地址和文章标题与所选条目一致；覆盖 AC4）。
- [x] 关闭索引后目录图恢复正常状态（验证：打开再关闭索引，期望面板消失、无关节点恢复正常透明度、焦点返回父目录且图仍可交互；覆盖 AC4）。
- [x] 页面没有搜索、过滤、排序切换或相关快捷键控件（验证：检查首页可见控件和生成 HTML，期望不存在上述功能入口）。
- [ ] 减少动态效果设置得到尊重（验证：浏览器模拟 `prefers-reduced-motion: reduce` 后开关索引，期望无位移或淡入过渡；覆盖 N4）。

## 集成

- [x] 目录数据能够完整传递到索引轨道（验证：比较 Hugo 输出的页面数量与索引递归结果，期望没有遗漏或重复链接）。
- [x] 索引轨道不直接控制 D3 或会话存储（验证：检查模块依赖和打包结果，期望索引模块只接收数据和回调，没有 D3 或存储访问）。
- [x] 图导航正确调用目录、索引和状态模块（验证：运行生产构建并完成“展开目录 → 打开索引 → 打开文章 → 返回首页”流程，期望各阶段状态连续）。
- [ ] 旧版会话状态仍可读取（验证：只写入旧的展开路径和焦点存储值后刷新首页，期望图正常恢复且索引保持关闭）。
- [x] 无效索引路径安全降级（验证：写入不存在的索引路径后刷新，期望首页显示正常目录图、无脚本异常，并清除无效索引状态）。
- [x] 特殊字符标题以普通文本显示（验证：使用包含 `<`、`&`、引号的隔离标题，期望字符原样显示且不生成额外页面元素）。
