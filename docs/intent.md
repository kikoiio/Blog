# 博客意图

## 用户
- 主要用户：Aries（站长）- 个人博客，用于计算机科学笔记和摄影作品
- 次要用户：对技术内容和摄影感兴趣的访客

## 目标
- 清晰优雅地展示博客内容
- 保留现有文章 URL 和内容结构
- 免费部署，可在中国大陆访问
- 简单、可维护的架构

## 非目标
- 无服务端渲染或数据库
- 无在线 CMS（内容通过 Git 管理）
- 无实时功能（评论、聊天等）
- 无商业功能或用户账户
- 无复杂交互元素（仅基础导航）

## 内容类型
- **笔记**：计算机科学文章、教程、项目文档
- **摄影**：按日期/地点组织的照片专辑

## 验收标准
- 文章和摄影专辑可访问且格式良好
- 网站加载快，支持移动设备
- 部署免费，可在中国大陆访问
- 保留现有文章 URL
