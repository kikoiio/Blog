# 博客意图

## 用户
- 主要用户：Aries（站长）- 个人博客，用于计算机科学笔记和摄影作品
- 次要用户：对技术内容和摄影感兴趣的访客

## 目标
- 清晰优雅地展示博客内容
- 保留现有文章 URL 和内容结构
- 免费部署，可在中国大陆访问
- 简单、可维护的架构
- 可扩展：未来可添加评论、用户系统等动态功能

## 非目标
- 无自建服务器（全部使用 Cloudflare 服务）
- 初期不需要在线 CMS（内容通过 Git 管理）
- 初期不需要用户账户系统
- 不追求复杂商业功能

## 内容类型
- **笔记**：计算机科学文章、教程、项目文档
- **摄影**：按日期/地点组织的照片专辑

## 技术路线
- **当前**：Next.js 静态导出 → Cloudflare Pages
- **可扩展**：Next.js → Cloudflare Workers + D1 + R2 + KV + Queue
- **图片**：本地存储 → 可迁移到 R2 或国内图床

## 验收标准
- 文章和摄影专辑可访问且格式良好
- 网站加载快，支持移动设备
- 部署免费（Cloudflare 免费额度），可在中国大陆访问
- 保留现有文章 URL
- 架构支持未来添加评论、用户系统等动态功能
