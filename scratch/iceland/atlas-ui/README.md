# 冰岛图集 UIUX 纵向切片

<http://127.0.0.1:8153/scratch/iceland/atlas-ui/>

这是独立可丢弃界面原型，不接入主原型，不新增运行依赖。目标是检验“风景 → 地图 → 文章”的清晰路径，而不是环境模拟。

- 首屏：完整风景、地点名、天气、一句描述，上一处 / 下一处 / 换天气。
- 地图：真实冰岛海岸线、冰川与 25 个地点，右侧显示选中地点预览。
- 文章：摘要目录先验证入口与层级；正文仍留在旧原型中。
- 键盘：M 地图，R 文章，Esc 关闭，←/→ 切换地点。
- 尊重 reduced motion；小屏改为纵向卡片式地图和文章列表。
