# Zima Blue · Liquid studies

对应 `docs/zima-visual-and-lusion-tactile-spec.md` 的独立原型，按第 8 节最新反馈加入有机微扰、焦散、环境反射和水色透射，保留第 7 节的纤细波列与无按压划水，以及第 6 节的浮点精度和法线平滑。无需依赖安装，也不接入 Hugo 构建。

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory scratch/prototype
```

打开 `http://127.0.0.1:4173`。点击留白或“触碰水面”产生主波前与衰减细波列，无需按压滑动鼠标即可划出连续尾迹；拖动浮标或聚焦后按方向键移动节点。下方阅读区可以选中文字；顶部按钮切换冷灰与深海模式。

## 实现与规格对应

- **浮点高度场**：WebGL 2 + `EXT_color_buffer_float`，RGBA16F 双缓冲保存当前与前一帧高度；检查 framebuffer 完整性。缺少能力时使用解析透镜，避免退回 8 位量化高度场。
- **浮点波动与平滑法线**：固定 60 Hz 步进、有界的速度冲量、边缘吸收和 9-tap Gaussian 高度滤波；法线单独在低分辨率缓冲中计算。粘滞系数为 0.055，避免粘滞项与波速叠加导致离散积分不稳定。
- **纤细波列**：以紧凑 Gabor 波包替代宽厚环形隆起，初始影响带宽从 0.13 收至 0.045，缩窄约 65%。一道主波前配合较弱的回弹波列，约 1.2 秒平复；使用 quintic 边缘截断 Gaussian 尾部，保持边界平滑。法线直接使用解析导数，取消旧的四次高度差分求导。
- **被动划水**：正常滑动振幅为点击的 15%～20%，极慢小幅移动进一步衰减；无需按压，没有原先 90 px/s 的硬门槛。轨迹先线性插值，再按连续线段注入。单帧最多 8 段，拥挤时合并同一笔相邻线段以保留覆盖，跨手势不连线；浮点与解析降级路径都保留滑动尾迹。
- **有机微扰**：点击波前叠加三阶、五阶角向微流，最大径向扰动 0.0014，随位置、波龄变化。使用平滑的中心过渡，并在法线与拉普拉斯曲率中包含扰动的一、二阶导数，避免光照与形变错位。
- **明暗焦散**：根据有符号曲率估算光线收敛率 `I = 1 / (1 + α∇²h)`，对收敛率和光强设限；波峰形成银白聚光、波谷形成浅影。平面曲率为零时，新增焦散与阴影均为零。覆盖率也感知曲率，保证斜率为零的波脊仍能显露聚光。
- **柔光反射**：以水的折射率 1.333 计算菲涅尔反射，叠加两块程序生成的柔光棚环境与微量连续虹彩；光照感知明暗主题，无外部环境贴图或常驻环境动画。
- **齐马蓝透射**：波高和表面倾斜决定有限光程，按 Beer–Lambert 指数吸收衰减 RGB，让红光比蓝光衰减更快，形成淡青水色。正文额外降低光学增益，背景最大位移仍为 14 CSS px，正文上限仍为 2.5 CSS px。
- **真实折射**：RGB 按 1.06 / 1.00 / 0.94 偏移采样场景，法线 Y 方向与场景纹理一起翻转；正文位移降为 40%，并只显示紧凑解析波包，排除高度场低频残留。按包络带宽与传播速度推算，单道波包在某一点的通过时间约为 0.14～0.16 秒；波前之外画布透明，直接显示原始 DOM。选中文字、键盘焦点区域显示原始 DOM，保留选择高亮与焦点轮廓。
- **按需运行**：GPU 归约高度场的动能与残余位移，每 150 ms 读取一个像素；结合透镜寿命和末段平滑退火，静止后停止 RAF 并清空残余高度。没有轮询计时器、自动演示波或常驻 CSS 动画。
- **边界与降级**：滚动剪切、切后台暂停、WebGL 上下文恢复、动态 reduced-motion 光晕模式、粗指针设备半分辨率、最大输出尺寸限制。

## 原型边界

焦散与环境光使用屏幕空间近似；尾迹曲率按连续胶囊截面估算。点击波的梯度及拉普拉斯曲率使用解析导数，并以有限差分交叉检查。

页面以可交互 DOM 为源，按明确标记的文字、圆角面板与连线绘制场景纹理。这个绘制器只服务当前画廊，不是通用网页截图方案；还不覆盖图片、代码块、任意 CSS 和 Hugo 文章。休眠时隐藏折射画布，保留原始页面。

浮标提供 `zima:node-motion` 适配事件，不加载或改动生产 D3 图谱。事件格式为：

```js
window.dispatchEvent(new CustomEvent('zima:node-motion', {
    detail: { x: 400, y: 300, vx: 180, vy: 80, source: 'drag' }
}));
```

可选 `startX/startY` 表示上一节点位置，提供后使用连续尾迹。`x/y` 为视口 CSS 像素，`vx/vy` 为 CSS 像素/秒。仅接受 `drag`、`hover`、`keyboard`，速度须超过 70 px/s；布局冷却事件不会注入波纹。主题事件兼容博客的 `onColorSchemeChange` 字符串 payload（`light` / `dark`）。
